# 🎨 Генератор Персонажей

Интерактивное Next.js приложение для создания уникальных персонажей путем выбора различных частей тела и аксессуаров.

## ✨ Возможности

- **Выбор частей тела**: Голова, тело, ноги, руки
- **Аксессуары**: Множественный выбор дополнительных элементов
- **Предпросмотр в реальном времени**: Видите изменения сразу при выборе
- **Генерация изображения**: Создание итогового изображения персонажа
- **Скачивание результата**: Сохранение сгенерированного персонажа

## 🚀 Запуск приложения

### Предварительные требования

- Node.js 18+ 
- npm или yarn

### Установка и запуск

1. **Клонируйте репозиторий**
   ```bash
   git clone <repository-url>
   cd character-generator
   ```

2. **Установите зависимости**
   ```bash
   npm install
   # или
   yarn install
   ```

3. **Запустите приложение в режиме разработки**
   ```bash
   npm run dev
   # или
   yarn dev
   ```

4. **Откройте браузер**
   Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000)

## 🛠️ Технологии

- **Frontend**: Next.js 15, React 18, TypeScript
- **Стилизация**: Tailwind CSS
- **Генерация изображений**: HTML5 Canvas API
- **Placeholder изображения**: SVG API endpoints

## 📁 Структура проекта

```
src/
```

## 🎯 Как использовать

1. **Выберите части персонажа**:
   - Кликайте на различные варианты головы, тела, ног и рук
   - Выбирайте аксессуары (можно выбрать несколько)

2. **Предпросмотр**:
   - В правой панели видите, как будет выглядеть персонаж
   - Все изменения отображаются в реальном времени

3. **Генерация**:
   - Нажмите кнопку "🎨 Сгенерировать персонажа"
   - Дождитесь создания итогового изображения

4. **Скачивание**:
   - Нажмите "💾 Скачать изображение" для сохранения результата

## 🔧 Настройка

### Добавление новых частей

Для добавления новых вариантов частей тела отредактируйте массив `AVAILABLE_PARTS` в файле `CharacterGenerator.tsx`:

```typescript
const AVAILABLE_PARTS = {
  head: [
    // Добавьте новые варианты здесь
    { id: 'head5', name: 'Голова 5', imageUrl: '/path/to/image.png' },
  ],
  // ... другие части
};
```

### Замена placeholder изображений

Замените URL в `imageUrl` на реальные изображения:

```typescript
imageUrl: '/images/head1.png'  // Вместо placeholder API
```

## 🎨 Кастомизация

- **Цвета**: Измените цветовую схему в Tailwind CSS классах
- **Размеры**: Настройте размеры canvas и изображений в `generateCharacter` функции
- **Стили**: Модифицируйте компоненты для изменения внешнего вида
